# 自动刷新脚本

Tampermonkey（篡改猴）自动刷新脚本：让任意网页按时间自动刷新。计时和定时两种模式，随时切换。

## 脚本一览

| 脚本 | 适用页面 | 设置方式 |
| --- | --- | --- |
| TeleAgent 刷新保活 | 只在 TeleAgent 工作台页面生效 | 改代码里的设置区 |
| 通用自动刷新 | 所有页面 | 改代码里的设置区 |
| 通用自动刷新（图形版） | 所有页面 | 右下角图形面板，点按钮改 |

## 安装

1. 安装 Tampermonkey：打开 Chrome 应用商店，搜索 Tampermonkey（篡改猴），点“添加至 Chrome”。
2. 打开 Chrome 扩展设置（chrome://extensions），点 Tampermonkey 的“详情”，把“允许运行用户脚本”打开（新版 Chrome 必须开，不然脚本不运行）。
3. 安装脚本（二选一）：
   - 方法一：把 `.user.js` 文件拖到 Chrome 窗口里，点“安装”。
   - 方法二：点 Tampermonkey 图标 → 添加新脚本 → 把脚本代码粘贴进去 → Ctrl+S 保存。

## 设置

代码版的设置区在文件最上面，全是中文：

- 模式：写 `'计时'` 或 `'定时'`。
  - 计时：每隔多少分钟刷一次（改 `间隔分钟`，默认 15）。
  - 定时：在每小时的第几分钟刷（改 `定时分钟`，00 到 59 都可以写，数字从小到大，想刷几次写几个，比如 `[0, 15, 30, 45]` 是每小时的 00、15、30、45 分刷新）。
- 改完按 Ctrl+S 保存，刷新页面就生效。

图形版不用改代码：打开任意页面，右下角有个“自动刷新”小面板，选模式、填分钟、点“开始”，面板上还会显示下次刷新时间和倒计时。

## 注意事项

- 同一个页面只开一个脚本，两个同时开会重复刷新。
- 正在填东西的页面会被刷新掉，不用的时候在 Tampermonkey 里把开关关掉。
- TeleAgent 工作台：同一个账号同时在两个浏览器登录会冲突，只有一个浏览器能连着云电脑。

## 文件

- `teleagent-auto-refresh.user.js` — TeleAgent 刷新保活（v4.0）
- `通用自动刷新.user.js` — 通用自动刷新（v1.0）
- `通用自动刷新-图形版.user.js` — 通用自动刷新（图形版，v1.0）
